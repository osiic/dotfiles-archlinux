# 👻 Ghostty Terminal Configuration

Modern, fast, native GPU-accelerated terminal configuration for **Ghostty** with Catppuccin theme colors and customized keybinds.

---

## ⚡ 1-Line Quick Setup

### Option A: Via SSH (Recommended)
```bash
git clone git@github.com:osiic/ghostty.git ~/.ghostty-config && cd ~/.ghostty-config && ./setup.sh
```

### Option B: Via HTTPS
```bash
git clone https://github.com/osiic/ghostty.git ~/.ghostty-config && cd ~/.ghostty-config && ./setup.sh
```

---

## 📂 Features
- Native GPU acceleration
- Font & layout customization
- Integrated Catppuccin themes
- Multi-distro auto-installer & Git auto-updater
