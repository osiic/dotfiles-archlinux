# 🐚 Shell Environment (Zsh, Bash & Starship Prompt)

Modern cross-platform shell configuration with **Starship prompt** (Catppuccin Mocha theme), fast aliases, auto-completion, and history optimizations. Works across **Arch Linux, Ubuntu/Debian, Gentoo, Fedora, Alpine, Void, macOS, and Termux (Android)**.

---

## ⚡ 1-Line Quick Setup

### Option A: Via SSH (Recommended)
```bash
git clone git@github.com:osiic/shell.git ~/.shell-config && cd ~/.shell-config && ./setup.sh
```

### Option B: Via HTTPS
```bash
git clone https://github.com/osiic/shell.git ~/.shell-config && cd ~/.shell-config && ./setup.sh
```

---

## 📦 What's Included & Managed
- `.zshrc` : Modern Zsh configuration with autosuggestions & syntax highlighting
- `.bashrc` & `.bash_profile` : Bash fallback & environment configuration
- `starship.toml` : Clean and fast Starship prompt
- `setup.sh` : Multi-distro auto-installer & Git auto-updater
